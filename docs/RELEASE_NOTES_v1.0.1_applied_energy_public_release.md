## Release scope

This version archives the public derived-data and reconstruction package used
to support manuscript-facing review of the AI token-energy telecoupling study.

Included:

- derived manuscript-facing source tables
- figure-source data
- claim-evidence matrix
- reconstruction script
- release-scope and licensing documents
- source-data and availability wording notes

Excluded:

- restricted third-party raw data
- provider routing logs
- facility-level electricity or GPU load records
- procurement-chain records
- hourly marginal-emissions data
- local caches and private working files

## Claim boundary

This public release supports audit of a bounded burden-geography screen based
on public evidence and derived source tables. It does not provide observed
provider routing, measured facility-level AI load, or procurement-resolved
attribution.
