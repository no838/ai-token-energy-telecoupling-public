# Release scope

This GitHub package is a lightweight schematic-code release for manuscript transparency.

## Included

- Lightweight plotting code for demonstration figures.
- Derived figure source-data tables copied from the final clean submission package.
- Claim-evidence and key-resource tables.
- Reference PNGs for manuscript-facing figures.
- Data and code availability text aligned with the manuscript claim ceiling.

## Excluded

- Raw upstream data whose redistribution terms require linking/citation rather than redistribution.
- Large intermediate caches and exploratory working outputs.
- Provider-routing logs, measured country-level AI electricity-load data, facility GPU utilization,
  provider procurement records, hourly marginal emissions, physical fuel procurement data, and
  AI-specific water-demand data. These are unavailable under the current public evidence frontier and
  were not used.
- Credentials, tokens, API keys, private notes, and local absolute-path working files.

## Intended use

The repository supports inspection and schematic rebuilding of public derived outputs. It should not be
cited as a complete reproduction of private routing or facility-load evidence.
