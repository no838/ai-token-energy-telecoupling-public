# Release scope

This repository is a manuscript-facing public derived-data and reconstruction
package.

## Included

- Reconstruction code for reviewer-facing reference outputs.
- Derived figure-source tables copied from the manuscript-facing package.
- Claim-evidence and key-resources tables.
- Reference figure assets used to audit visual reconstruction.
- Data/code availability text aligned with the manuscript claim ceiling.
- Release-scope, licence and third-party data boundary notes.

## Excluded

- Raw upstream data whose redistribution terms require linking or citation
  rather than redistribution.
- Large intermediate caches and exploratory working outputs.
- Provider routing logs, measured country-level AI electricity-load data,
  facility GPU utilization, provider procurement records, hourly marginal
  emissions, physical fuel-procurement data and AI-specific water-demand data.
- Credentials, tokens, API keys, private notes and local absolute-path working
  files.

## Intended use

The repository supports inspection and reconstruction of manuscript-facing
derived outputs. It should be cited as a public derived-data and reconstruction
package rather than as a redistribution archive for restricted raw data or
higher-resolution private evidence classes.
