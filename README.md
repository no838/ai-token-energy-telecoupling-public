# Public derived data and reproducibility scripts for AI data-centre burden-geography screening

This public release contains derived tables, figure-source data, provenance notes and a compact Python reproduction script for a public-data screening study of AI data-centre electricity and carbon burden geography.

## Scope

The release supports inspection of the public-data screening layer. It does not redistribute restricted upstream raw records and does not contain provider-controlled routing logs, facility-load measurements, procurement contracts or private endpoint data.

## Contents

- `derived_tables/`: figure-source tables, supplementary tables, null-model diagnostics, grouped sensitivity summaries and claim-evidence matrices.
- `analysis_ready/`: analysis-ready benchmark and host-plausibility component tables.
- `scripts/recompute_fig3_ablation.py`: compact script for reproducing the Figure 3A-D evidence-class ablation diagnostics from included tables.
- `reproduced_outputs/`: outputs generated by the reproduction script.
- `metadata/`: schema-lock and claim-boundary notes for public benchmark layers.
- `MANIFEST.csv` and `SHA256SUMS.txt`: file inventory and checksums.

## Quick Start

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/recompute_fig3_ablation.py
```

Expected outputs are written to `reproduced_outputs/`.

## Evidence Boundary

The included materials support reproduction and audit of the public-data screening calculations. They do not convert the analysis into observed provider routing, measured AI facility load, procurement-chain tracing or facility-level attribution.
